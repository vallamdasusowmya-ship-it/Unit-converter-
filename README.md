# Unit Converter

## Description
This is a simple C program that converts values between different units.

## Conversions Available
1. Kilometers to Meters
2. Meters to Kilometers
3. Meters to Centimeters
4. Centimeters to Meters
5. Kilograms to Grams
6. Grams to Kilograms
7. Celsius to Fahrenheit
8. Fahrenheit to Celsius

## Language Used
- C

## How to Run
Compile the program using a C compiler and run the executable.

## Example
Input:
5 km

Output:
5000.00 m
